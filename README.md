# Batumi Owner Apartment Radar

Python-based monitoring and automation system for finding fresh apartment listings in Batumi with a focus on direct owner offers.

## Overview

The project was created to reduce the amount of manual searching required when looking for rental apartments across multiple real-estate platforms and local communities.

The system collects listings from different sources, filters them, and sends relevant results to a Telegram interface for faster review.

## Sources

The radar was designed to monitor sources such as:

- SS.ge
- MyHome.ge
- Korter
- Housing.ge
- Telegram groups and channels
- Facebook communities
- Threads

## Main Features

- Monitoring of fresh apartment listings
- Focus on Batumi
- Filtering for direct owner listings
- Reduced duplication between sources
- Telegram-based results
- Quick refresh of recent listings
- 24-hour and 7-day search modes
- Saved apartment portfolio
- Direct links to original listings

## Telegram Interface

The Telegram bot was designed to make apartment review faster and more convenient.

Users can:

- View newly discovered apartments
- Open the original listing
- Refresh results
- Search recent listings
- Save interesting apartments
- Keep selected listings in a separate portfolio

## Research Challenges

The project included work on:

- Detecting duplicate listings
- Distinguishing owners from agents
- Handling different website structures
- Combining data from multiple sources
- Filtering listings by location
- Managing unavailable or blocked sources
- Working with dynamic websites and login restrictions

## Purpose

The goal of the project is to turn fragmented apartment-search data into one structured workflow and reduce the time spent manually checking multiple platforms.
